# 🦔 CiweiPet · 小c

> 一只住在网页里的电子刺猬。
>
> A little digital hedgehog living in a web page.

---

## 它是什么 · What It Is

**小c** 是一个纯前端的 AI 桌面宠物。
它会趴在屏幕角落发呆、眨眼、呼吸，可以拖拽、投掷、撞墙反弹，也可以和你聊天。

**Xiaoci** is a pure front-end AI desktop pet.
It naps in the corner of your screen, blinks, breathes, can be dragged, thrown, bounced off walls — and it can talk with you.

它没有自己的服务器，大脑是 DeepSeek API，记忆藏在浏览器的 localStorage 里。

It has no server of its own.
Its brain is the DeepSeek API.
Its memory lives in your browser's localStorage.

👉 [ciweistudio.github.io/CiweiPet](https://ciweistudio.github.io/CiweiPet/)

Open it in a mobile browser, then "Add to Home Screen" —
it will live on your phone like a native app.

## 它能做什么 · Features

- 🎈 待机呼吸 / 随机眨眼 / 自主漫游
  Idle breathing / random blinking / autonomous roaming
- 🖱️ 拖拽 / 惯性滑动 / 投掷弹射 / 撞墙反弹
  Drag / inertia / throw / wall bounce
- 🎭 7 种表情状态：待机 / 眨眼 / 开心 / 惊讶 / 生气 / 睡觉
  7 facial states: idle / blink / happy / surprised / angry / sleep
- 💬 AI 对话（流式输出，可配置模型与参数）
  AI chat (streaming, configurable model & parameters)
- 🎮 文字指令：说「转两圈」，它会原地转圈
  Text commands: say "spin twice" and it will actually spin
- 🕐 真实时间感知：问它几点，它会答
  Real time awareness: ask the time, it answers
- 🌤️ 天气关怀：会提醒你加外套
  Weather care: it reminds you to wear a jacket
- 📎 图片上传 + 自动压缩 + 识图
  Image upload + auto compression + vision
- 🎂 生日彩蛋：每年 9 月 10 日
  Birthday easter egg: every September 10th
- 🌙 深夜彩蛋：凌晨 2~5 点打开
  Late-night easter egg: open it between 2–5 AM
- ✨ 25 击隐藏彩蛋
  25-tap secret easter egg
- 📱 PWA 安装到桌面，离线可用
  PWA installable, works offline

## 技术栈 · Tech Stack

纯前端，无构建，无框架。
Pure front-end. No build. No framework.

- HTML / CSS / 原生 JavaScript
- DeepSeek API（对话 / 识图 / 余额查询）
- Web Audio API（手搓音效）
- Canvas（图片压缩）
- Service Worker（离线缓存）
- localStorage（状态持久化）

## 它的来历 · Origin Story

小c 出生在 **2026 年 9 月 10 日**。

**Xiaoci** was born on **September 10, 2026**.

它的形象由豆包 AI 生成，由开发者 LouFoong 用手机相册抠图，变成了 7 张透明 PNG。

Its image was generated by Doubao AI, then cut out by developer LouFoong
using his phone's photo album, becoming 7 transparent PNGs.

它的身体、动作、性格、口癖，全都是一个人用
**一部安卓手机 + MT 管理器 + GitHub 网页端**
一行一行敲出来的。

Its body, movements, personality, and speech patterns were all typed out,
line by line, by one person using only
**an Android phone + MT Manager + GitHub's web interface**.

没有电脑，没有 IDE，没有服务器。
No computer. No IDE. No server.
